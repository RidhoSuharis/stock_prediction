# v1.0.0

Rilis awal StockPredict, aplikasi web untuk memprediksi harga penutupan saham menggunakan model Bi-LSTM.

**Tanggal Rilis:** 8 November 2026

## Fitur

- Prediksi harga penutupan saham BBCA dengan model Bi-LSTM.
- Horizon prediksi 1 dan 5 hari perdagangan.
- Recursive multi-step forecasting untuk prediksi beberapa hari ke depan.
- Unggah data historis CSV dengan validasi di browser dan server.
- Template CSV konsisten, mendukung delimiter koma atau titik koma dan baris `sep=`.
- Nama file template unik menggunakan timestamp.
- Popup peringatan ketika data kurang dari 30 baris.
- Grafik harga historis dan hasil prediksi.
- Antarmuka responsif dengan Basecoat UI yang di-host sendiri.

## Perbaikan

- Validasi ekstensi `.csv`, ukuran maksimal 5 MB, dan kolom `Date` serta `Close`.
- Validasi tanggal, harga positif, tanggal duplikat, dan minimal 30 baris data.
- Penanganan error pada form dan proses prediksi.

## Teknis

- Flask, TensorFlow, scikit-learn, pandas, dan Gunicorn.
- Struktur service modular untuk model per saham.
- Dockerfile dan Docker Compose untuk deploy ke VPS.
- Dokumentasi deploy VPS, Nginx, HTTPS, dan pembaruan aplikasi.
- Panduan kontribusi `AGENTS.md` dan dokumentasi proyek `README.md`.

## Catatan

- Versi ini baru menyediakan model BBCA dengan horizon 1 dan 5 hari.
- Seluruh angka merupakan estimasi model, bukan rekomendasi investasi.
